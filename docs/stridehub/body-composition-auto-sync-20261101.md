# 体成分展示与 Android 自动同步 · 2026-11-01

## 行为变化

手机采集已包含完整计算快照，但网页原先只显示日体重投影。身体与减重页面现在共用体成分面板，展示逐次采集的 27 类已知指标、原始算法评级、参考区间和计算依据；未知指标也保留显示。可选择历史测量，默认刷新跟随最新记录，手动历史选择保持不变。缺失值与数值零分别处理，体重保留两位小数。

体检报告中的身高可作为独立 BMI 依据。选择有版本冲突保护及来源指纹，报告修改或删除后停止使用失效引用。原始采集资料、BMI 和所有体成分估算不被重算或覆盖。骨量、身体年龄与基础代谢附有含义限制；算法评级不作为医学诊断或自动减重处方。

Android 0.3.4（versionCode 8）在测量本机保存成功后立即尝试上传。前台恢复网络、重新打开 App 与登录续期会补传已授权记录，持久任务负责后台重试，回执自动刷新页面状态。保存先于队列操作，网络或队列失败不会撤销测量；串行发送、固定 UUID 和冻结载荷防止重复创建。尚未授权的历史不因打开 App 自动上传，切账号或撤销设备不会自动重新配对。

本机数据库 v6→v7 仅新增可空的归属标记，旧测量、导入记录、计算快照与上传队列保持不变。服务器使用现有版本化存储保存身高选择和审计记录，无新增数据库结构迁移。

## 验证

- 健康领域、API 与 MCP：167 项测试、1149 断言通过。
- 浏览器回归：完整指标、数值精度、缺失与零、骨量提示、XSS、默认最新刷新、历史跨页、日期切换、请求失败及不确定写入、320px 布局通过。
- 独立本地预览的真实浏览器操作验证：选择报告身高后显示独立 BMI，保留原始 BMI 和全部 28 个合成测试指标，API 回读一致。
- Android JVM：55 项通过；模拟器 instrumentation：37 项通过，包括立即上传、离线恢复、重复触发、账号切换、撤销、队列故障、SQLite v6→v7 和界面回执刷新。
- 正式签名包构建成功；lint 无 error，仍有非阻断 warning。

真实手机的 BLE 称重、系统后台限制和安装后自动同步需在覆盖安装新版后验证。模拟器结果不代表真实手机已经升级。本记录不声称生产部署完成；生产发布另行执行停写备份、全业务数据比对与公网校验。

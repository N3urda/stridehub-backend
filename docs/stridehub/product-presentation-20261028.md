# Android 产品展示优化与验证

2026-10-28，基于 `codex/native-android` / `495a14a54`，实现位于 `native-android` 工作树。本轮调整主页面的信息层级、主要操作与统一视觉，延续「总览、身体、称重、运动、计划」五个一级栏目。

## 展示结构

| 页面 | 首要任务 | 展示调整 |
| --- | --- | --- |
| 总览 | 看最近身体记录，直接开始称重 | 体重主卡优先展示测量值、日期与称重按钮；睡眠、步数、静息心率分层呈现，下方连接今日安排、下一项训练、近期运动及同步。服务器记录与本机称重历史保留区分。 |
| 身体 | 看一段时间内的变化 | 首屏保留完整称重入口；提供近 7/30/90 天及自定义日期，最新体重与睡眠摘要、身体记录入口、体重/睡眠曲线和每日指标。睡眠与日指标先显示 5 条，可展开完整历史。 |
| 称重 | 连接设备、测量和回看本机记录 | 常驻主导航中间，与其他栏目共用主题和导航；首次使用提供设备插图和添加引导，收到读数后再展示本次测量区域。手工记录、最近历史、设备帮助和同步各有清楚入口。登录页提供无需连接服务器的离线入口。 |
| 运动 | 看运动积累，继续记录或复盘 | 期间统计集中展示次数、距离、可读时长与心率；日期筛选收纳展开，类型筛选保持直接可选。新增/导入作为主要操作，分析/同步作为快捷入口。记录卡区分名称、时间、类型、来源和各项指标，详情先呈现核心数据再呈现曲线。 |
| 计划 | 先处理今天，再管理长期安排 | 今日安排与训练反馈置于首位；其余入口按训练与目标、饮食与补给、身体感受分组。原训练课表、健康计划、减重目标、赛事、训练偏好、饮食计划、饮食记录和补给记录均可继续进入。 |

五个栏目使用统一的深青色主色、浅色或深色页面背景、卡片、图标、文字层级与间距。原生图表保留实际采样点和缺口，增加最高/最低值层级及选中位置提示。通用指标对长日期和来源字段保留标签和值的可读空间。

大字号（字号缩放至少 1.5）下，运动页新增、导入、分析、同步改为纵向全宽操作，避免并排按钮拆开中文词语。常规字号保留双列布局。

## 数据与状态

- 缺失值仍显示 `—` 或缺失说明，不把未测量的心率、体重、睡眠或运动累计值补成零，也不生成健康判断。
- 睡眠与运动时长转换为小时、分钟等可读格式；单位和日期仍可见。存在待核对运动来源时，继续遵守服务器对累计统计的限制。
- 空页面说明当前范围没有记录，并提供称重、调整范围、导入或同步等后续入口。没有记录不表示用户从未称重或运动。
- 已有缓存时，以紧凑状态条显示更新中或离线缓存及保存时间；连接失败详情可展开并重试。缓存回退的 `warning` 与直接请求失败均可显示，权威认证/业务错误仍按既有策略处理。
- 相对日期以服务器时区的当前日期判断，避免跨日打开缓存时，把旧记录误标为「今天」。

界面继续使用原生 Compose 和既有原生 Java 称重视图，不引入 WebView。本轮不涉及服务器 API、存储结构或数据库迁移，称重 SQLite、测量 UUID、上传队列及账号隔离缓存继续复用原实现。

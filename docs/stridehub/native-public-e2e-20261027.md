## 真实故障与修复

公网网关日志确认两次 `POST /admin/app/mobile/v1/sessions` 返回 500。旧 App 将用户粘贴的网页路径 `/admin/app` 当作安装目录，拼出了错误登录路径。另一个独立问题是网关未转发 `/mobile/v1/`；正确根路径的请求此前落到 Panel，返回 200 HTML，未到原生接口。

0.3.1 将已知管理页面地址归一到安装根，保留实际子目录、端口及地址安全校验。网关新增明确的原生登录和移动接口转发，保持 Panel 根路径和其他站点配置。登录页支持密码显隐、网址键盘、粘贴提示和提交中的禁用状态；错误密码、代理 HTML、重定向、TLS、超时与服务器 JSON 错误分别显示可辨认的原因。

没有引入 WebView。源码构建门禁和最终 APK 的两份 DEX 检查均通过。
